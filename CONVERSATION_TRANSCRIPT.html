3 App Crash Diagnosis & Fixes

1. ViewModel Reflection NoSuchMethodException

Compose's viewModel() default factory uses reflection to call <init>(Application). Without @JvmOverloads, Kotlin only generated the 2-arg constructor in JVM bytecode, crashing the app on startup. We added @JvmOverloads and an explicit ViewModelProvider.Factory.

2. Experimental Navigation 3 Runtime Backstack

Experimental Navigation 3 threw polymorphic serialization errors. We updated MainActivity.kt to launch MainScreen() directly within the Material 3 light theme surface, bypassing runtime reflection failures.
